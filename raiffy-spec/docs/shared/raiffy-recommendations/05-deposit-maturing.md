# 05 · Term deposit about to renew

| Field | Value |
| --- | --- |
| Kind | `depositMaturing` |
| Needs | `savings` |
| Trigger | A term deposit matures within 14 days and is set to renew automatically |
| Deadline | The maturity date · last notice 7 days before |
| Card | "Your **15,000 lei** deposit renews on **4 Nov** at today's rate, 5.1%. You opened it at 5.6%." |
| Source | From your deposit and rates as of 28 Oct |
| Button | Compare before it renews |
| Opens Raiffy with | "My deposit renews on 4 Nov. Should I renew it or move it?" |
| Answer | Scope `solution`: renew as it is, renew for a different term, move to a savings account, or government bonds, with one recommended for the customer's access needs. |
| Can lead to | Deposit settings (change the term or stop renewal), open a savings account |
| Retires when | The deposit matures or the renewal setting changes |
| Demo figures | 15,000 lei · 6 months · opened 4 May at 5.6% · renews at 5.1% |
