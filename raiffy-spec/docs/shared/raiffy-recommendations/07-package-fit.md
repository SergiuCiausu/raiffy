# 07 · Account package fit

| Field | Value |
| --- | --- |
| Kind | `packageFit` |
| Needs | `account`, `transactions` |
| Trigger | Over the last 6 months, another package would have cost at least 60 lei a year less for the same use |
| Card | "Your account package costs **19 lei** a month. For how you've used it since May, a 9 lei package would have covered everything: **120 lei** less a year." |
| Source | From your May to October statements |
| Button | Check your package |
| Opens Raiffy with | "Is my account package still the right one for me?" |
| Answer | Scope `compare`: the current package and the one that fits, with what each covers, what the customer actually used and the yearly cost of each. Says plainly what they'd lose by switching. |
| Can lead to | Change package (official flow) |
| Retires when | The package changes, or the saving drops under 60 lei a year |
| Demo figures | Current package 19 lei/month · used: transfers, 1 Raiffeisen ATM withdrawal a week · fitting package 9 lei/month |

Also works the other way: if the customer pays more in separate fees than a bigger package would cost, the card says so with the same rules.
