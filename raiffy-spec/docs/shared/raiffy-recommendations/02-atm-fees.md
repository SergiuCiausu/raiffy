# 02 · Other banks' ATM fees

| Field | Value |
| --- | --- |
| Kind | `atmFees` |
| Needs | `transactions` |
| Trigger | 2 or more withdrawals at other banks' ATMs in a month |
| Card | "You paid **15 lei** in ATM fees in October: 3 withdrawals at other banks' ATMs." |
| Source | From your October transactions |
| Button | See how to avoid them |
| Opens Raiffy with | "Why did I pay 15 lei in ATM fees?" |
| Answer | Scope `detail`: what the package covers, the Raiffeisen ATMs nearest to where the withdrawals happened, and whether a different package would pay off at this rate of use. Ends with a question about the package. |
| Can lead to | ATM map, package comparison (07) |
| Retires when | No such fee for 2 months in a row |
| Demo figures | 3 × 5 lei · 22, 25 and 29 Oct · nearest Raiffeisen ATM 400 m away |
