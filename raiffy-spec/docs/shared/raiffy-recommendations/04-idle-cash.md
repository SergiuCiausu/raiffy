# 04 · Money sitting idle

| Field | Value |
| --- | --- |
| Kind | `idleCash` |
| Needs | `account`, `transactions` |
| Trigger | For 3 months, the current account balance stayed at least 5,000 lei above the customer's usual monthly spending |
| Card | "About **12,000 lei** has stayed in your current account for 3 months, earning 0.05%." |
| Source | From your August to October statements |
| Button | See where it could earn more |
| Opens Raiffy with | "I have about 12,000 lei I'm not using. Where could it earn more?" |
| Answer | Scope `solution`: at least three routes ranked by how easily the money can be taken out (savings account, term deposit, government bonds), with one recommended for keeping an emergency buffer available. |
| Can lead to | Open a savings account or term deposit (official flow) |
| Checks | Never counts money needed for the next month's usual spending; no card if the overdraft is in use |
| Retires when | The idle amount drops under 5,000 lei |
| Demo figures | 12,000 lei idle · 0.05% current account · savings 3.5% · 6-month deposit 5.6% · 1-year bonds 6.2% |
